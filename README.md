## What I am investigating

My current research starts with a practical question:

> How can we test machine learning models for discriminatory behavior using realistic test cases for causal and counterfactual scenarios? Furthermore, how can we mitigate bias in the models with different levels of access?

I have researched the following topics:

- **Model-agnostic fairness testing:** evaluating black-box decision models 
  without relying on internal model access.
- **Natural changes in tabular data:** modifying an attribute while preserving
  realistic relationships with the remaining attributes.

## Featured research thread

### Fairness testing in the latent space of a generative model

I applied t-way combinatorial testing inside a Variational AutoEncoder latent
space to generate natural test cases for black-box fairness testing.

[Paper](https://ieeexplore.ieee.org/stamp/stamp.jsp?arnumber=10962484)

I am extending this line of work by studying natural, minimally changed
counterfactual examples for tabular data.

[Current research notes](https://ajdahal.github.io/natural_changes.html)
